# Portafolio de Juan Sebastián Pinzón

Sitio estático multipágina. Página de inicio: `index.html`.

## Publicación en GitHub Pages
1. Sube todos los archivos y carpetas de este proyecto al repositorio.
2. En GitHub abre Settings → Pages.
3. En Build and deployment selecciona Deploy from a branch.
4. Elige `main` y `/ (root)`, guarda y espera la publicación.

Los videos están integrados desde YouTube. Si un reproductor no carga, cada tarjeta ofrece el enlace alternativo a YouTube. Los archivos de nómina incluidos usan datos de demostración anonimizados; no publiques archivos originales con datos personales.
